# Skill: apply dcc-care design system

Apply the "Discipline Ledger" system to any DCC Care surface. Load
`tokens/colors_and_type.css` for values; link `ui-kit.css` from mockups.

## Identity

- Primary: evergreen `#14442C` (surfaces, primary actions). Gold `#D4A017` is a
  precision accent — active nav, scan CTA, key numerals, focus rings. Never
  large gold fills except the scan button and brand mark.
- Paper `#F7F6F0` app background; white cards; `#F1EFE6` sunken surfaces.
- Text: green-cast ink scale (`--ink-1..4`); never pure black.
- Severity stamps: Minor (sage), Major (gold), Serious (amber), Grave (red) —
  bordered uppercase letterspaced chips, never solid fills.

## Type

- Display/headers & stat numerals: Fraunces (600).
- UI/body: Instrument Sans (400–600).
- IDs, student numbers, RFID hex, timestamps: JetBrains Mono.

## Motifs

- Ledger tables: sunken small-caps header row, hairline rows, tabular numerals.
- Case-file framing: mono case numbers (`OFF-2026-0042`), ID chips, receipt-like records.
- Crisp radii (4/8/12), minimal offset shadows, 120–180ms ease-out motion.
- Prohibitions: no bluish-purple gradients, no emoji-as-icons, no rounded cards
  with colored left-border strips, no generic admin-template blues.
